# Phase-1: Cybersecurity Tools

A collection of cybersecurity tools developed to support security analysis, system auditing, and Indicators of Compromise (IOC) extraction. This repository contains two independent tools built with Bash and Python.

## Repository Structure

```text
Bash-Tool-Python-Tool-Phase-1/
                          ├── Bash-Tool/
                          │   ├── tool.sh
                          │   ├── README.md
                          │   └── screenshots/
                          └── Python-Tool/
                              ├── tool.py
                              ├── README.md
                              └── screenshots/
```

##  Tools Overview

### 1. Linux Security Checker — Bash

A Bash-based tool designed to assist with Linux security checks and system auditing.

- Performs security-related checks on Linux systems.
- Provides terminal-based output for reviewing findings.
- Supports read-only checking, according to the tool's implementation.
- Includes screenshots and a dedicated README with usage instructions.

**Location:** `Bash-Tool/`

### 2. IOC Extractor — Python

A Python-based tool designed to extract Indicators of Compromise (IOCs) from supported input data.

- Helps identify potential security indicators.
- Provides terminal-based results for analysis.
- Supports cybersecurity investigation and threat-analysis workflows.
- Includes screenshots and a dedicated README with usage instructions.

**Location:** `Python-Tool/`

## Requirements

Requirements depend on the tool and the operating system.

- **Bash Tool:** A compatible Linux environment .
- **Python Tool:** Python 3 and any additional dependencies specified in its internal README.

Kali Linux or another compatible Linux distribution may be suitable for testing the Bash tool.

## Getting Started

Clone the repository:

```bash
git clone "https://github.com/saifullahsafi/Bash-Tool-Python-Tool-Phase-1.git"
```

Run the Bash tool:

```bash
cd Bash-Tool3
chmod +x tool.sh
./tool2.sh
for Full access
sudo ./tool2.sh
```

Run the Python tool:

```bash
cd ../Python-Tool
python3 tool.py
```

Follow each tool's internal `README.md` for detailed requirements, options, and usage instructions.
